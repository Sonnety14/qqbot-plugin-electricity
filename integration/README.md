# QQ 独立电费绑定桥接

此处保存 v1.0.2 配套网站服务的电费路由和迁移代码，不是可独立运行的服务器。需要既有 site_service 的数据库、identity、store、内部桥接鉴权及 FastAPI 路由挂载。不得直接暴露内部桥接接口或信任网页传来的 QQ 号。

用户直接私聊“绑定宿舍”后填写宿舍。无需网站登录或预先关联 QQ；网站电费绑定入口已移除，旧写入接口返回 410。24 小时冷却和个人预警开关按 QQ 保存。

部署前一致性备份 SQLite。迁移保留原绑定内部 ID、版本、冷却、开关，使加密凭据及日提醒去重记录继续可用。旧表仅保留回退，新表 electric_qq_* 为唯一读写来源；存在重复 QQ 身份时迁移会拒绝，须核对后处理，不能静默合并。
